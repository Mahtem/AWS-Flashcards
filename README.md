# AWS-Flashcards
Overview

AWS Flashcards is an educational Android application containing 425 flashcards to support learning and revision of Amazon Web Services (AWS) concepts.

Key Features

425 learning flashcards

Topics organised around AWS certification exam-guide domains

Additional 114 cards introduced following a review of topic coverage

Designed for self-study and exam preparation

Download

The Android APK is available in this repository. Download the APK file to install the application on an Android device.
